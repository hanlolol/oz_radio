오즈 라디오 프로젝트 (Foundation Document v1.1)
1. 프로젝트 개요 
•	오즈 라디오 프로젝트는 문학 텍스트를 활용한 배경형 언어 학습 서비스이다.
•	사용자는 화면을 보지 않아도, 다른 일을 하면서도 문학 작품을 통해 자연스럽게 외국어에 노출된다.
•	핵심 콘셉트는 다음 한 문장으로 요약된다. > 문학을 읽는 앱이 아니라, 문학을 틀어두는 언어 라디오 
•	초기 데모 및 MVP는 퍼블릭 도메인 작품인 오즈의 마법사(The Wizard of Oz) Chapter 1을 기반으로 한다.
2. 해결하려는 문제 
•	페이지 단위 번역: 학습에 너무 큼 
•	문장 단위 번역: 문맥 붕괴, 리듬 단절 
•	오디오북: 이해 불가 시 학습 종료 
•	팟캐스트: 난이도·콘텐츠 통제 불가 
•	문단 단위 + 자동 번역 + 반복 청취를 통해, “이해를 포기하지 않아도 되는 오디오 학습”을 제공한다.
3. 타겟 사용자 
•	1차 타겟 
o	중급 이상 외국어 학습자 
o	출퇴근·운동·집안일 중 학습을 원하는 사용자 
o	오디오북은 어렵고, 공부 앱은 피곤한 사용자 
•	2차 타겟 
o	집중 학습이 어려운 사용자 
o	장시간 배경 오디오 소비자 
4. 핵심 차별점 
•	문단 단위 학습 : 의미·장면·서술 단위 유지 , 듣기 집중 한계에 최적화 
•	라디오 모드 UX : 화면 최소, 손 조작 최소 , 자동 재생, 자동 반복 
•	이중 언어 TTS 자동 결합 : 원문 → 번역 자연 전환 , 별도 설명 멘트 없음 
5. MVP 기능 정의 (필수 3개) 
•	문단 단위 라디오 모드 재생 
o	[문단 원문] → [문단 번역] 자동 진행 
o	(신규) 번역 데이터 이중화 지원 (문학형 / 직역형 선택 재생)
•	언어별 고정 TTS + 속도 차이 
o	원문: 느리게 (0.9~0.95x) 
o	번역: 기본 속도 (1.0x) 
•	챕터 자동 반복 : 챕터 종료 시 처음부터 재생 , 백그라운드 청취 가능 
6. 라디오 모드 UX 플로우 (요약 - v1.1 업데이트) 
•	책 선택 → 챕터 선택 
•	(신규) 진입 시 번역 모드 기본값 선택 (문학형 / 직역형)
•	라디오 모드 시작 
•	(신규) 플레이어 화면 내 직관적인 [문학 ↔ 직역] 토글 버튼 활성화 (터치 시 다음 문단부터 즉시 적용)
•	자동 음성 흐름: 
o	문단 원문 TTS 
o	무음 (0.6~0.9초) 
o	(수정) 선택된 모드의 문단 번역 TTS (문학형 또는 직역형)
o	무음 (0.9~1.2초) 
•	챕터 끝 → 자동 반복 
•	앱 재실행 시 마지막 문단 이어 듣기 
7. TTS 두 언어 자연 결합 설계 (완성본) 
•	핵심 규칙 : 언어별 고정 보이스 , 미세한 속도 차이 , 언어 전환 시 무음 삽입 , 언어 전환 안내 멘트 금지 
•	표준 음성 패턴 : [원문 문단] ↓ 0.8s [번역 문단] ↓ 1.1s 
•	성공 기준 : 언어 전환이 자연스럽게 인지됨 , 피로·이질감 없음 
8. 데모 상태 (현재) 
•	작품: The Wizard of Oz, Chapter 1 
•	분량: 초반 6문단 데모 스크립트 완성 (문학형, 직역형 JSON 데이터 확보 완료)
•	용도: 라디오 모드 10~15분 청취 테스트
